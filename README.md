# ClaseFit

App móvil para ver las próximas clases de un gimnasio, reservar un cupo y cancelar la reserva.

El MVP usa datos locales. El socio ya está autenticado. No hay login ni backend.

## 📱 Descarga

**Android (APK):**
[Descargar ClaseFit v1.0](https://github.com/yoryi/claseFit/releases/tag/1.0)

## Stack

* React Native con Expo
* TypeScript
* Jest

## Cómo correrla

Desde la carpeta `src/`:

```bash
npm install
npm start
```

* Android: `npm run android`
* iOS: `npm run ios`
* Web: `npm run web`

## Pruebas

```bash
cd src
npm test
```
