# Preguntas de reflexión · Desarrollador React Native espartano

Copia este archivo como `respuestas_reflexion.md` en tu repositorio y responde con tus propias palabras. Puedes apoyarte en la IA para ordenar ideas, pero queremos **tu** opinión. De 3 a 5 líneas por pregunta es suficiente.

---

### 1. ¿Qué experiencia previa tenías usando OpenSpec o SDD?

No tenía experiencia previa con OpenSpec ni SDD. Lo que hice fue investigar cómo funciona y probarlo para entender la metodología y su flujo de trabajo.

### 2. ¿Cómo crees que cambia el rol de desarrollador React Native antes y después de conocer y aplicar este framework?

Creo que uno pasa de simplemente desarrollar a pensar primero qué se necesita construir y cómo debe funcionar. También ayuda mucho cuando se trabaja con IA, porque mientras mejor definido esté el requerimiento, mejores resultados se obtienen.


### 3. ¿Cómo crees que debería trabajar ahora un equipo que usa esta metodología?

Creo que el equipo debería trabajar primero en definir claramente el objetivo y los requerimientos antes de comenzar a desarrollar. Después dividir el trabajo en tareas pequeñas, implementar y validar que el resultado cumpla con lo definido


### 4. ¿Qué ventajas y desventajas ves?

Ventajas: ayuda a tener mayor claridad sobre lo que se va a desarrollar, reduce errores y facilita que todo el equipo tenga el mismo entendimiento. Además, creo que funciona muy bien cuando se trabaja con IA.

Desventajas: requiere más tiempo al inicio y, si no se aplica con criterio, puede generar demasiada documentación para cambios que realmente son sencillos.


### 5. ¿Cuándo usarías y cuándo no usarías este método?

Lo usaría para funcionalidades complejas o proyectos donde se necesite buena organización y coordinación.

No lo usaría para cambios pequeños o tareas muy sencillas, porque sería innecesario.
